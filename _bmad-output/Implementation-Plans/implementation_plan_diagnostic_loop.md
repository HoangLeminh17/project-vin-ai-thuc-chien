# Implementation Plan: Diagnostic Loop & Pipeline Optimization

Bản kế hoạch này mô tả các bước kỹ thuật để triển khai hệ thống chẩn đoán học tập và tối ưu hóa pipeline xử lý tài liệu.

## 🛠 Milestone 1: Core Pipeline & Traceability

### 1.1. Tối ưu hóa MinerU Adapter
- **Vấn đề:** Timeout 300s không đủ cho file > 200 trang.
- **Giải pháp:** 
    - Tăng `timeoutMs` lên 900,000 (15 phút).
    - Kiểm tra API MinerU xem có hỗ trợ `is_ocr_only: true` hoặc các model mạnh hơn cho tiếng Việt.
    - Đảm bảo `language: 'vi'` được gửi chính xác.

### 1.2. Traceability (Tru xuất nguồn gốc)
- **Mục tiêu:** Lưu mapping giữa nội dung bài giảng/câu hỏi và tài liệu gốc.
- **Hành động:**
    - Cập nhật `IDocumentParser` để trả về metadata cho mỗi chunk (page index, line range).
    - Cập nhật `GenerateCourseUseCase` để yêu cầu AI đính kèm `source_chunk_id` vào mỗi Quiz Question.
    - Cấu trúc file `content_list_parsed.md` cần chứa các anchor IDs.

## 🛠 Milestone 2: Diagnostic Loop System

### 2.1. Diagnostic Quiz Generator (Backend)
- **Use Case:** `GenerateDiagnosticQuizUseCase`.
- **Logic:** 
    - AI quét `content_list_parsed.md`.
    - Sinh 15-20 câu hỏi đa dạng chủ đề.
    - Mỗi câu hỏi có schema: `{ question, options, answer, explanation, source_chunk_id, topic }`.

### 2.2. Confidence Capture & Priority Map
- **UI:** Thêm bước chọn mức độ tự tin (Confident, Unsure, Guess) trước khi hiện đáp án.
- **Logic:** 
    - Tính toán điểm ưu tiên (Priority Score) dựa trên: `is_correct` AND `confidence_level`.
    - `Guess + Correct` -> High Priority (May mắn, cần học lại).
    - `Unsure + Incorrect` -> High Priority.
    - `Confident + Correct` -> Low Priority.
- **Output:** Trả về `StudyPriorityMap` (Topics grouped by priority).
